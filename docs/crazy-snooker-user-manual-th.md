ระบบ Crazy Snooker Club เป็นศูนย์ควบคุมการดำเนินงานของคลับสนุกเกอร์ โดยรวมการขายหน้าร้าน การชำระเงิน สถานะโต๊ะ สมาชิก การจอง คลังสินค้า ใบเสร็จ และประวัติรายการไว้ในระบบเดียว คู่มือนี้อธิบายการปฏิบัติงานประจำวันในเวอร์ชันที่เผยแพร่ปัจจุบัน

## 1. เริ่มต้นใช้งาน

| เมนู | วัตถุประสงค์หลัก |
| --- | --- |
| **จุดขาย POS** | ขายสินค้า สแกนบาร์โค้ด และเริ่มรายการรับชำระเงิน |
| **สมาชิกและ Wallet** | ตรวจสอบยอดคงเหลือและสร้าง QR สำหรับเติมเงินสมาชิก |
| **จองโต๊ะและแจ้งเตือน** | บันทึกการจองโต๊ะและทดสอบเงื่อนไขแจ้งเตือนใกล้หมดเวลา |

ก่อนเปิดกะ ให้ตรวจสอบว่าหน้าเว็บแสดงข้อความ **“กะปัจจุบันเปิดอยู่”** ที่มุมขวาบน และตรวจสอบสถานะโต๊ะให้ตรงกับสภาพจริงของคลับ

## 2. การขายสินค้า ณ จุดขาย POS

เปิดเมนู **จุดขาย POS** แล้วเลือกสินค้าได้สองวิธี วิธีแรกคือคลิกที่บัตรสินค้า วิธีที่สองคือสแกนบาร์โค้ดด้วยเครื่องสแกนที่ทำงานเสมือนแป้นพิมพ์ หรือพิมพ์รหัสลงในช่องค้นหาแล้วกด `Enter` หรือปุ่ม **ค้นหา** สินค้าที่พบจะถูกเพิ่มลงตะกร้า และยอดรวมจะคำนวณใหม่โดยอัตโนมัติ

ในตะกร้า ใช้ปุ่ม **−** เพื่อลดจำนวน และ **+** เพื่อเพิ่มจำนวน พนักงานควรตรวจสอบชื่อสินค้า จำนวน และยอดรวมก่อนสร้าง QR ชำระเงินทุกครั้ง หากสินค้าไม่มีจำนวนคงเหลือ ระบบจะแจ้งว่าไม่สามารถเพิ่มสินค้านั้นได้

| ขั้นตอน | การปฏิบัติ |
| --- | --- |
| 1 | เพิ่มสินค้าลงตะกร้าด้วยการคลิกหรือสแกนบาร์โค้ด |
| 2 | ตรวจสอบจำนวนและยอดรวมในตะกร้า |
| 3 | กด **สร้าง QR PromptPay** |
| 4 | ให้ลูกค้าสแกน QR และแสดงหลักฐานการชำระเงิน |
| 5 | พนักงานตรวจสอบยอด แล้วกด **พนักงานยืนยันรับชำระแล้ว** |
| 6 | เปิดหรือพิมพ์ใบเสร็จที่ระบบสร้างหลังยืนยัน |

> **ข้อสำคัญ:** QR จะอยู่ในสถานะ **รอตรวจสอบ** จนกว่าพนักงานจะยืนยัน ระบบจะไม่ตัดสต็อกหรือสร้างธุรกรรมสมบูรณ์ก่อนการยืนยันดังกล่าว

หากระบบแจ้งว่า `PROMPTPAY_RECIPIENT ยังไม่ได้ตั้งค่า` หมายความว่ายังไม่ได้กำหนดบัญชีหรือหมายเลข PromptPay ของคลับ จึงยังสร้าง QR รับเงินจริงไม่ได้ ให้ติดต่อผู้ดูแลระบบเพื่อดำเนินการตั้งค่า

## 3. สมาชิกและการเติมเงิน Wallet

ในเมนู **สมาชิกและ Wallet** ให้คลิกเลือกสมาชิกจากรายการด้านซ้าย ระบบจะแสดงยอดคงเหลือ เบอร์โทร และคะแนนสะสม ระบุยอดเงินที่ต้องการเติมในช่องจำนวนเงิน แล้วกด **สร้าง QR เติมเงิน**

การยืนยันรับชำระเงินมีหลักการเดียวกับ POS กล่าวคือ พนักงานต้องตรวจสอบการชำระเงินก่อนกดยืนยัน เมื่อยืนยันสำเร็จ ยอด Wallet ของสมาชิกจะเพิ่มตามจำนวนที่ระบุ ควรตรวจสอบชื่อสมาชิกก่อนเริ่มรายการทุกครั้งเพื่อป้องกันการเติมเงินผิดบัญชี

## 4. การจองโต๊ะและการแจ้งเตือน

เปิดเมนู **จองโต๊ะและแจ้งเตือน** เลือกโต๊ะ ระบุชื่อลูกค้า เบอร์โทรศัพท์ และเวลาเริ่มเล่น จากนั้นกด **บันทึกและแจ้ง LINE OA** ระบบจะบันทึกข้อมูลการจองและพยายามส่งแจ้งเตือนผ่าน LINE OA เมื่อมีการตั้งค่าช่องทาง LINE ครบถ้วน

ในส่วน **แจ้งเตือนก่อนหมดเวลา** สามารถกด **ทดสอบส่งแจ้งเตือน** เพื่อตรวจสอบรูปแบบการทำงานได้ ระบบมีงานตรวจสอบเวลาเล่นที่ทำงานทุก 1 นาทีในเวอร์ชันเผยแพร่ และส่ง LINE Messaging API Push Message ได้เมื่อโต๊ะเข้าสู่ช่วงใกล้หมดเวลาตามที่กำหนด

| สถานการณ์ | ข้อความหรือผลลัพธ์ที่ควรคาดหวัง |
| --- | --- |
| LINE OA ตั้งค่าครบ | ระบบส่ง LINE Messaging API Push Message สำหรับการจองและการแจ้งเตือนใกล้หมดเวลา |
| LINE OA ส่งไม่สำเร็จ | ระบบจะแจ้งข้อผิดพลาดที่ปลอดภัย ให้ตรวจ userId/groupId และตรวจว่าบอตเข้าถึงปลายทางได้ |
| ข้อมูลลูกค้าขาด | ระบบขอให้กรอกชื่อลูกค้าและเบอร์โทรก่อนบันทึก |

## 5. สถานะโต๊ะแบบเรียลไทม์

เมนู **สถานะโต๊ะ** ใช้ติดตามความพร้อมใช้งานของโต๊ะในคลับ สถานะแต่ละประเภทมีทั้งข้อความและสีประกอบ เพื่อให้ตีความได้แม้ผู้ใช้มองสีได้ไม่ครบถ้วน

| สถานะ | สี | ความหมายและการปฏิบัติ |
| --- | --- | --- |
| **ว่าง** | เขียว | พร้อมรับลูกค้าใหม่ |
| **ไม่ว่าง** | แดง | กำลังมีลูกค้าใช้บริการ |
| **จองแล้ว** | เหลืองอำพัน | จองล่วงหน้า รอการมาถึงของลูกค้า |
| **ปิดปรับปรุง** | เทา | งดรับลูกค้าระหว่างซ่อมบำรุงหรือทำความสะอาด |

เปลี่ยนสถานะโดยเลือกค่าที่ต้องการจากเมนูในบัตรของโต๊ะ ระบบจะแสดงข้อความยืนยัน และข้อมูลบนหน้าจออื่นที่เปิดระบบอยู่จะปรับตามเหตุการณ์เดียวกัน โปรดเปลี่ยนโต๊ะเป็น **ไม่ว่าง** ทันทีเมื่อลูกค้าเริ่มใช้บริการ และเปลี่ยนเป็น **ว่าง** เมื่อตรวจสอบการชำระเงินและเก็บโต๊ะเรียบร้อยแล้ว

เมื่อเลือกสถานะ **ไม่ว่าง** จะมีช่อง **เวลาเลิกเล่น** ปรากฏในบัตรโต๊ะ ให้กำหนดวันและเวลาที่คาดว่าลูกค้าจะเล่นเสร็จ แล้วคลิกออกจากช่องเพื่อบันทึก ระบบจะเก็บเวลานี้ไว้ถาวรและตรวจสอบทุก 1 นาที เมื่อเข้าสู่ช่วงใกล้หมดเวลาที่กำหนด ระบบจะรับสิทธิ์แจ้งเตือนเพียงครั้งเดียวต่อรอบเวลาเล่น จึงช่วยป้องกันการส่งข้อความซ้ำ หากมีการเปลี่ยนเวลาเลิกเล่น ให้กำหนดเวลาใหม่เพื่อเริ่มรอบการติดตามใหม่

บัตรโต๊ะที่กำลังเล่นจะแสดงป้ายเวลาแบบสดและอัปเดตเป็นระยะ ได้แก่ **เหลือเวลา** สำหรับเวลาปกติ, **ใกล้หมดเวลา** เมื่อเหลือไม่เกิน 15 นาที และ **เกินเวลา** เมื่อผ่านเวลาเลิกเล่นแล้ว ให้พนักงานใช้ป้ายนี้ประกอบการแจ้งลูกค้าและสรุปค่าบริการ โดยยังควรตรวจสอบเวลาเลิกเล่นจริงก่อนปิดรายการ

## 6. คลังสินค้าและบาร์โค้ด

ในเมนู **คลังและบาร์โค้ด** ให้สแกนหรือพิมพ์บาร์โค้ดสินค้า แล้วกด **ค้นหาสินค้า** เมื่อระบบพบสินค้า จะแสดงชื่อสินค้าที่สแกนพร้อมตัวเลือกการทำรายการและจำนวน ให้เลือก **รับสินค้าเข้า** เมื่อนำสินค้าเข้าคลัง หรือ **ปรับสินค้าออก** เมื่อแก้ไขยอดคงเหลือลดลง จากนั้นกด **บันทึกรายการจากบาร์โค้ด**

พนักงานยังสามารถใช้ปุ่ม **+ รับเข้า** และ **− ปรับออก** ในแถวสินค้าได้สำหรับการปรับครั้งละหนึ่งหน่วย หากใช้กล้องสแกน ระบบอาจขอสิทธิ์เข้าถึงกล้อง หากอุปกรณ์ไม่รองรับหรือไม่อนุญาต ให้ใช้เครื่องสแกนบาร์โค้ดหรือพิมพ์รหัสแทน

> **ข้อสำคัญ:** การสแกนในหน้าคลังจะเลือกสินค้าเพื่อทำรายการสต็อกเท่านั้น และจะไม่เพิ่มสินค้าเข้าสู่ตะกร้า POS โดยอัตโนมัติ

## 7. ใบเสร็จ การพิมพ์ และอีเมล

หลังพนักงานยืนยันรับชำระเงิน ระบบจะสร้างข้อมูลใบเสร็จสำหรับรายการนั้น ใบเสร็จประกอบด้วยเลขที่ใบเสร็จ เลขอ้างอิง วันเวลา ลูกค้า วิธีชำระเงิน รายการสินค้า และยอดชำระรวม

กด **พิมพ์ใบเสร็จ** เพื่อเปิดหน้าพิมพ์ของเบราว์เซอร์ โดยระบบจะซ่อนเมนูและส่วนควบคุมที่ไม่เกี่ยวข้องจากเอกสารพิมพ์ หากต้องการเตรียมส่งให้ลูกค้าทางอีเมล ให้กรอกอีเมลในช่อง **ส่งผ่านอีเมล** แล้วกด **เตรียมอีเมลใบเสร็จ** ระบบจะเปิดโปรแกรมอีเมลของพนักงานพร้อมหัวเรื่องและข้อมูลใบเสร็จ ให้ตรวจสอบผู้รับและข้อความก่อนกดส่ง

การทำงานปัจจุบันเป็นการ **เตรียมอีเมลผ่านโปรแกรมอีเมล** ไม่ใช่การส่งอีเมลอัตโนมัติจากเซิร์ฟเวอร์ จึงไม่ควรแสดงต่อผู้ใช้ว่าระบบส่งสำเร็จจนกว่าพนักงานจะกดส่งจริง

## 8. ค้นหาและกรองประวัติรายการ

เปิดเมนู **ประวัติรายการ** เพื่อดูธุรกรรมที่รับชำระแล้ว สามารถใช้ตัวกรองหลายรายการร่วมกันได้ ได้แก่ วันที่เริ่มต้น วันที่สิ้นสุด ช่องทางชำระเงิน และคำค้นหา โดยคำค้นหาตรวจสอบจากเลขอ้างอิง ชื่อลูกค้า หรืออีเมลลูกค้า

| ตัวกรอง | วิธีใช้ |
| --- | --- |
| **ตั้งแต่** | เลือกวันที่เริ่มต้นของช่วงที่ต้องการตรวจสอบ |
| **ถึง** | เลือกวันที่สิ้นสุด ระบบรวมรายการตลอดทั้งวันนั้น |
| **ชำระผ่าน** | เลือก PromptPay, เงินสด, Wallet, บัตร หรือทุกช่องทาง |
| **ค้นหา** | พิมพ์เลขอ้างอิง ชื่อ หรืออีเมลลูกค้า |
| **ล้างตัวกรอง** | กลับไปแสดงรายการทั้งหมด |

กด **เปิดใบเสร็จ** ที่รายการที่ต้องการเพื่อตรวจสอบหรือพิมพ์ใบเสร็จย้อนหลัง ใช้ปุ่ม **รีเฟรช** หากต้องการโหลดข้อมูลรายการล่าสุดอีกครั้ง

## 10. ข้อควรปฏิบัติในการใช้งาน

พนักงานควรยืนยันยอดชำระเงินจริงก่อนกดรับชำระทุกครั้ง ไม่เปิดเผยภาพ QR หรือข้อมูลลูกค้าต่อบุคคลที่ไม่เกี่ยวข้อง และตรวจสอบสถานะโต๊ะให้ตรงกับการใช้งานจริงอย่างสม่ำเสมอ เมื่อพบข้อมูลคลาดเคลื่อน ให้แก้ไขสถานะหรือบันทึกการปรับสต็อกทันที พร้อมแจ้งผู้จัดการเมื่อเป็นรายการที่มีผลต่อยอดเงินหรือสินค้าคงเหลือจำนวนมาก
